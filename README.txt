Real Estate Price Predictor

Deployment:
1. Upload all files in this folder to a GitHub repository.
2. In Streamlit Community Cloud, create an app from that repository.
3. Set the main file path to app.py.

The app retrains the same Linear Regression model using the included Excel dataset,
an 80/20 split, and random_state=42. Prediction history is kept for the current
browser session and can be downloaded as CSV.

Price unit: 10,000 New Taiwan dollars per ping.
